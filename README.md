# Memories - Personal Greeting & Music Dedication Box

A beautiful, responsive, single-page greeting website designed to dedicate warm moments, custom messages, and soothing music to a special friend.

## Features
- **Watercolor Hero Scene**: Features a cozy attic studio illustration that serves as the visual centerpiece.
- **Skeuomorphic Audio Player**: Interactive vintage cassette tape widget playing ambient lo-fi music with custom play, pause, rewind, mute, and volume controls.
- **Parchment Letter Card**: A classic pinned letter layout with warm handwritten fonts displaying your custom letter message.
- **Interactive Memory Cork Board**: Draggable sticky notes and polaroid cards where visitors can drag memories around or pin new ones dynamically with interactive effects and pushpins.
- **Floating Ambience**: Generates subtle floating music notes, sparkles, and hearts that rise from the audio player when music is active.

- FontAwesome Icons

## Customizing
To change the track or text:
- Edit the audio source in `index.html` to link to your custom track.
- Edit the text inside the letter section in `index.html` to write a personal message.
